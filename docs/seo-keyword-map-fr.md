# Keyword map: FRENCH (Google Canada, French queries)

Researched independently of the English map using the Semrush Canada database, which returns French-language queries typed in Canada. Competitor pages are the French-first Quebec sites that actually rank for French terms. Volumes are monthly searches; KD = keyword difficulty.

**French-specific findings (not translations of English targets):**
- Core French head term is **iptv québec** (6.6k, KD11) plus **quebec iptv**, **iptv qc**, **iptv au quebec**; English equivalents are weaker.
- Regional term **iptv cote nord** (880, KD1) has no English counterpart: dedicated French-only page created.
- French users say **télévision ip / tv sur ip / tv par ip / télé ip** (1.9k, 1.3k, 590, 110) and **tvbox** (1.3k), not "iptv" alone: used in the French what-is and box guides.
- The #6 result for **iptv québec** is a legality article, so the French legality guide is framed as "légal ou illégal au Québec".
- French searchers use competitor **brand names** (diablo tv 1.6k, racoon tv 1.3k, bentv 320): intentionally NOT targeted (trademarks, different intent).
- **abonnement / forfait / pas cher / meilleur** are the French commercial modifiers; "essai gratuit" has KD1-6.
